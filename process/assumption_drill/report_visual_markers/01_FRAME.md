# Frame: visual markers in the Project 3 report

**The artifact:** the DSA5208 Project 3 report, `build/report/DSA5208_Project3_Report.pdf`, pages 1-25 (the rest is a code
appendix). A 10-pt single-column LaTeX article: numbered sections and subsections, long prose paragraphs, about 20
tables and 12 figures. (given)

**The reader:** the grader, Anthony Chen, who taught the course (MPI, OpenMP, GPU offload, CG, the cost model). He reads it
on screen, as one of many group reports, with the Lecture 12 grading slide in mind. Behind him are the two students, who
must be able to explain every sentence. (given in the earlier drill, `../report_language_pass/01_FRAME.md`)

**The user's words (13 Nov), verbatim:**
- "add a colon here Summary. We solve the Poisson equa, and probably of required, something to highlight pr underline,
  because the document os very dense, so some visual markers per say ?"
- After being offered (1) a bold lead-in sentence opening each paragraph, (2) a shaded "Key results" box under the Summary,
  (3) a shaded "What this shows" takeaway box closing each results section: "no that would look ai like".
So the user decided that those three devices are out. Underlining was also advised against (in a PDF it reads as a link).

**After reading, the reader should:** find each graded item where he expects it and follow each section in one pass
without the density hiding the structure, and nothing on the page should look machine-made. (inferred from the user's
words and the earlier drill)

**Unknown:** whether any visual marker is needed at all, or whether the density is better fixed by layout (paragraph
length, displayed equations, lists, figure and table placement, whitespace, subsection granularity); which devices
human-written reports of this kind actually use, and how often.

**Default sketch (the training-data hypothesis):** add emphasis devices on top of the existing text (bold phrases, boxes,
highlighted numbers) so a skimming reader can pick out results. The user rejected this level as AI-like. The reason to
test: the dense look may come from structure (long uniform paragraphs, numbers inline instead of displayed, no visual
rhythm), not from a lack of emphasis.
